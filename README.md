## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Mod List** | Organize installed mods with tags, priority and enable toggles |
| **Load Order** | Drag-to-reorder mod load priority with conflict highlighting |
| **Conflict Checker** | Detect file conflicts between installed mods |
| **Profile System** | Save named mod configurations to switch between setups |
